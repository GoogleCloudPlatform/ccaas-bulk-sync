How Synchronization Works

  1. Managed users. CCaaS users who have the User Sync Custom Role are managed by this service. Users without it are never changed or deactivated.
  2. Directory users. The service reads the members of every mapped directory group (optionally including members of nested groups) from Google Workspace, Active Directory or Microsoft Entra ID.
  3. Roles and teams accumulate. A user gets every role and joins every team from every mapping whose group they are in.
  4. Adds. Directory users who aren't in CCaaS, or whose managed account is inactive, are added with the sync role and their mapped roles and teams.
  5. Updates. Managed users whose roles, teams or names differ from the directory are updated.
  6. Deactivations. Active managed users who are no longer in any mapped group are deactivated.
  7. Existing users. Directory users who already exist in CCaaS without the sync role are skipped and reported, or adopted if Existing CCaaS Users is set to Adopt.
  8. Submit. All changes are submitted as one CCaaS bulk job, which is validated, processed and tracked under Jobs and Runs.

Safety checks

  • A sync stops if a mapped group can't be found, or if the directory returns no users at all.
  • Max Deactivations per Sync blocks scheduled syncs that would deactivate more users than the limit; manual syncs ask for confirmation.
  • Only one live sync runs at a time. Use Simulate Only to preview every change before applying it.

Google Workspace Service Account Setup

To allow this application to read users and groups from Google Workspace, you need to create a Google Cloud Service Account and grant it specific, read-only permissions.

  1. Go to the Service Accounts page in the Google Cloud Console.
  2. Create a new service account.
  3. Create a JSON key for the service account and download it.
  4. Go to the Google Workspace Admin Console.
  5. Navigate to Security > Access and data control > API controls.
  6. Click Manage Domain-Wide Delegation and add a new API client.
  7. For the Client ID, use the `client_id` from the downloaded JSON key.
  8. For the OAuth Scopes, add the following two scopes:
    • https://www.googleapis.com/auth/admin.directory.user.readonly
    • https://www.googleapis.com/auth/admin.directory.group.readonly
  9. Click Authorize.

Once complete, import the downloaded JSON key file or paste its contents into the text area.
